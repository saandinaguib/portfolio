Journal de stage — Semaine 3
26–30 mai

Pages Contact & À propos + Panier JavaScript

Développement des pages Contact et À propos en HTML/CSS. Pour le panier, le problème était qu'on n'a pas de base de données. J'ai réfléchi et j'ai utilisé le localStorage : j'ai intégré du JavaScript qui, à chaque clic sur "Ajouter au panier", sauvegarde l'article dans la mémoire du navigateur. Comme ça, même en changeant de page, le panier garde les produits en mémoire jusqu'à la commande.

HTMLCSSJavaScriptPanierlocalStorage

JavaScript — Sauvegarde du panier dans le navigateur

// Ajouter un article au panier
function ajouterAuPanier(nom, prix, image, taille) {
  var panier = localStorage.getItem('panier');
  if (panier == null) {
    panier = [];
  } else {
    panier = JSON.parse(panier);
  }
  panier[panier.length] = { nom, prix, image, taille };
  localStorage.setItem('panier', JSON.stringify(panier));
  alert(nom + ' ajouté au panier !');
}

2–6 juin

Recherche JavaScript, formulaire de contact & page commande

J'ai intégré du JavaScript dans la page Vêtements pour filtrer les produits en temps réel selon ce que l'utilisateur tape, sans recharger la page. Pour le formulaire de contact, j'avais initialement prévu de le traiter en PHP — mais GitHub Pages ne supporte pas PHP car il ne fait que du HTML/CSS/JavaScript. J'ai donc cherché une alternative simple et j'ai trouvé Formspree : un service gratuit qui reçoit les données du formulaire et les envoie directement par mail à Rayan LEPORI sans aucun code serveur. Il suffit de changer l'attribut action du formulaire avec l'URL fournie par Formspree. Pour la commande, le client remplit un formulaire avec ses coordonnées et son adresse de livraison. À la validation, Formspree envoie un mail à Rayan LEPORI avec le récapitulatif marqué "Non payé". La commande est aussi sauvegardée en localStorage avec le statut "en_attente" avant que le client soit redirigé vers PayPal.

9–13 juin

Paiement PayPal, page confirmation & mise en ligne

Quand le client clique sur "Payer", un lien le redirige vers PayPal avec le montant pré-rempli. Initialement j'avais prévu que PayPal redirige automatiquement le client vers ma page confirmation.html après le paiement — cela nécessite de configurer une URL de retour dans les paramètres PayPal, fonctionnalité réservée aux comptes Business. J'ai tenté de convertir mon compte en compte Professionnel mais cela demandait des informations fiscales (numéro de TVA, identifiant fiscal) que je ne possède pas en tant qu'étudiant. J'ai donc opté pour une solution alternative : après le paiement PayPal, un message sur la page commande invite le client à cliquer sur un lien "Confirmer ma commande" qui le redirige vers confirmation.html. Sur cette page, JavaScript lit le localStorage, passe le statut à "payé", vide le panier et affiche le récapitulatif complet. Rayan doit vérifier lui-même sur son PayPal que le paiement est bien arrivé avant de préparer la commande. Ensuite mise en ligne sur GitHub Pages et tests.
